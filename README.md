# Тетрис — игра в цвете

Браузерный тетрис на белом фоне с семью цветами фигур, предпросмотром, тенью приземления, уровнями и локальным рекордом. Без внешних зависимостей, шрифтов и сервисов.

## Запуск

Нужен Node.js 20 или новее.

```sh
cd /workspace/tetris
npm start
```

Сервер слушает порт 3000; переменная `PORT` позволяет выбрать другой порт.

```sh
npm test
```

Тесты проверяют перемешивание фигур, столкновения, поворот, сброс, очистку линий, уровни и завершение игры. Сборка и установка пакетов не требуются.

## Управление

← / → — движение, ↑ — поворот, ↓ — ускорение, пробел — мгновенный сброс, P / Escape — пауза, Enter — начало или продолжение игры. На небольших экранах доступны кнопки управления. При переключении вкладки игра автоматически ставится на паузу.

За 1 / 2 / 3 / 4 линии начисляется 100 / 300 / 500 / 800 очков × текущий уровень. Каждые 10 линий увеличивают уровень и скорость. Мягкий сброс даёт 1 очко за клетку, мгновенный — 2. Рекорд хранится в браузере, если доступно локальное хранилище.

## GitHub Pages

В репозитории откройте **Settings → Pages → Build and deployment → Source → GitHub Actions**.
После отправки ветки `main` workflow `Publish Tetris to GitHub Pages` проверит тесты и опубликует игру. Результат смотрите во вкладке Actions.
Адрес после успешной публикации: https://maxots27.github.io/tetris/ .
Сайт статический: на GitHub Pages Node.js и работающий сервер не нужны.
